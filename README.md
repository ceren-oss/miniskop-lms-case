#  Miniskop LMS Case Study

Welcome!  
This case study is designed to understand your **technical skills, problem-solving approach, and product thinking**.

At Miniskop, we build products that transform how children learn.  
We are looking for people who don’t just write code, but **build meaningful systems**.

---

Objective

Create a simple **Learning Module (LMS)** where a student can:

- Watch a video  
- Track progress  
- Mark the lesson as completed  

---

Requirements

Your solution should include:

- Video player (YouTube embed is fine)  
- Progress indicator (e.g. % completion)  
- “Mark as completed” functionality  
- Clean and simple interface  

---

Technical Expectations

- You are free to use any technology  
- Frontend is required  
- Backend is optional (mock data is fine)  
- Code should be clean and readable  

---

Submission

Please share:

- GitHub repository link  
- Short explanation:
  - What did you build?  
  - What would you improve?  
  - How would you scale this system?  

---

Timeline

Expected completion time: **2–3 days**

---

Important Note

We are not looking for perfect design.  
We are looking for:

- Clear thinking  
- Simplicity  
- Good structure  

---

Bonus (Optional)

If you want to stand out, you may add:

- User authentication  
- Multiple lessons structure  
- Progress persistence (local storage / backend)  

---

Tip

Keep it simple.  
Make it work.  
Make it clear.

---

Good luck! 🚀  
We’re excited to see how you think.
